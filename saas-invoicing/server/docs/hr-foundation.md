# HR foundation

The Phase 5 foundation provides tenant-scoped employee and department records. Employee
numbers are generated by PostgreSQL per tenant (`EMP-000001`, etc.); callers must not
rely on numbers being globally unique.

Only administrators can currently read or manage these records. Employee mutations
validate the department and reporting-manager references through tenant-scoped foreign
keys, and all API queries include the authenticated tenant. The supported employment
types are `permanent`, `contract`, `temporary`, `intern`, `casual`, and `consultant`.
Statuses are `active`, `inactive`, `suspended`, and `terminated`.

This step deliberately excludes payroll, compensation, national identifiers, bank
details, attendance, and leave data. A department must be created before it can be
selected for an employee. The employee number counter and uniqueness constraints are
database-backed, so concurrent registrations remain safe.
